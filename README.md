# LeetCode Submission Archiver

Automatically archive all of your own LeetCode submissions to GitHub.

Repository:

https://github.com/nikil3406/LeetCode

## Features

- Search LeetCode by question number
- Access your own submission history
- Retrieve every submission
- Preserve old submissions
- Detect already archived submissions
- Support multiple programming languages
- Store runtime and memory
- Create a README for every problem
- Automatically commit files to GitHub
